# Cupo · Landing de carga compartida

Página estática (un solo `index.html`, sin dependencias ni compilación).

## Publicar en Vercel
1. Sube esta carpeta a un repositorio nuevo en GitHub.
2. En vercel.com → Add New → Project → importa el repositorio.
3. Framework Preset: **Other**. Sin comando de build. Output: la raíz.
4. Deploy. Cada `git push` a `main` vuelve a publicar la página.

## Antes de publicar, reemplaza
- `51000000000` en los enlaces de WhatsApp por tu número (formato 51 + número, sin espacios ni +).
- Todo lo que está entre corchetes: [PRECIO], [— TN], [MÍNIMO], [NÚMERO], [CORREO] y las respuestas de preguntas frecuentes.
- El nombre "Cupo" si eligen otro.
